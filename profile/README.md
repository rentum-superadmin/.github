# Rentum

**Rent, in one place.** Hostel and PG management for owners, wardens and residents — rooms and
beds, stays, bills and branded receipts, check-out settlements, complaints, announcements,
mandatory Aadhaar/DigiLocker verification and a cross-hostel red-flag registry.

| Repository | What |
|---|---|
| `rentum-api` | Spring Boot 3 / Java 21 backend, PostgreSQL 16 |
| `rentum-clients` | React web app + React Native mobile app + shared packages |
| `rentum-infra` | Environments, deployment, backups |
| `rentum-docs` | Requirements, plans, ADRs, brand |

All repositories are private. Trunk-based development on `main`; releases by tag.
