# Security policy

Report vulnerabilities privately to the organisation owners (GitHub → Security → Report a
vulnerability on the affected repository, or email the address on the org profile). Please do not
open public issues for security problems. We aim to acknowledge within 2 business days.

Hey PG handles Aadhaar-derived identity data; see `heypg-docs/requirements` §9.5 for the
compliance checklist every change touching verification must satisfy.
